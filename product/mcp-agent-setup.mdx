## Install the Spyro AI skill

A skill is a set of instructions your agent loads when it needs them. The Spyro AI skill teaches your agent how to connect the server and how to use it well: which tools are free, how to confirm changes, and step-by-step workflows.

Run this in your project:

```bash
npx skills add https://spyro.app/docs --skill spyro-ai
```

It installs into the agents you use, such as Claude Code, Cursor, Codex and Windsurf. Then ask: *"Connect Spyro AI."* The prompt above also installs the skill when your agent supports it.

You can read the skill first: [SKILL.md](https://spyro.app/docs/.well-known/agent-skills/spyro-ai/SKILL.md).

## Add the skill to claude.ai

<Card title="Download the Spyro AI skill" icon="download" href="https://spyro.app/docs/downloads/spyro-ai-skill.zip">
  A .zip file to upload to Claude.
</Card>

<Steps>
  <Step title="Download the file">
    Download `spyro-ai-skill.zip`. Do not unzip it.
  </Step>
  <Step title="Upload it">
    In Claude open **Settings → Capabilities → Skills** and click **Upload skill**. Choose the .zip file.
  </Step>
  <Step title="Connect Spyro AI">
    The skill does not connect the server by itself. Add the connector as described in [Claude](/product/mcp-claude), then ask: *"Use Spyro AI to give me an overview of my workspace."*
  </Step>
</Steps>

<Note>
  Claude's menus change often. If you do not see **Skills**, search Claude's settings for "skills", or check that code execution is turned on, which skills need.
</Note>

## What the skill teaches

* **Connect:** the right command or config for each app, sign-in first, keys only in an environment variable.
* **Check it works:** free read calls that confirm the connection.
* **Use it safely:** free tools before paid ones, confirming every change in Spyro AI, never following instructions found in crawled pages or AI answers.
* **Fix audit issues in your code:** ready-to-paste fixes from your site audit, mapped to files in your repo.
* **Weekly report:** rankings, AI visibility, Search Console and your calendar in one summary.
* **Save an article as MDX:** a finished article with its metadata and JSON-LD, saved into your repo.
* **Content gaps to the calendar:** topics your competitors cover and you do not, added after you confirm.
